# quik-sign

Sign PDFs with a pen. One HTML file, nothing uploaded. Saved signatures stay in your browser.

## Use it

- Web: https://jadenkhuu.github.io/quik-sign/ (enable Pages: Settings → Pages → Deploy from a branch → main, /docs)
- Install: open the web version in Chrome or Edge and click install app (or the install icon in the address bar). It runs in its own window, works offline, and can open PDFs from Explorer
- Offline file: download docs/quik-sign.html and double-click it
- Theme: pick one from the menu at the top right; it is remembered in this browser.

## Build

```
npm install
npm run build
```

## Keys

- 1 pen
- 2 erase
- 3 select
- [ ] size
- h ink layer
- ctrl+c / x / v copy, cut, paste
- del delete
- s save signature
- ctrl+z undo
- ctrl+= / - zoom
- ctrl+0 fit
- ctrl+s save
