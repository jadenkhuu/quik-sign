# quik-sign

Sign PDFs in your browser. Nothing is uploaded.

**https://jadenkhuu.github.io/quik-sign/**

Works offline. In Chrome or Edge, click install app to use it in its own window.

## Keys

| key | action |
| --- | --- |
| 1 / 2 / 3 | pen / erase / select |
| [ ] | pen size |
| s | save signature |
| h | show or hide ink |
| ctrl+c / x / v | copy / cut / paste |
| del | delete |
| ctrl+z | undo |
| ctrl+= / - / 0 | zoom in / out / fit |
| ctrl+s | save pdf |

## Develop

```
npm install
npm run build
```
