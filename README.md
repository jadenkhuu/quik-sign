# nib

One HTML file. Open `dist/nib.html` in a browser, drop in a PDF, sign it, save. Nothing is uploaded or stored.

## Build

```
npm install
npm run build
```

## Keys

- p pen
- e erase
- v select
- 1–4 size
- h ink layer
- t theme
- ctrl+c / x / v copy, cut, paste
- del delete
- ctrl+z undo
- ctrl+s save
